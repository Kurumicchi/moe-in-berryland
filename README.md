# 🍓 Moe in Berryland

A small 2D game project made with **C++ and SFML**.

> A personal project created to explore game development, object-oriented programming, sprite animation, map systems, and game state management.

## 🎮 About

**Moe in Berryland** is a 2D game prototype developed as an individual programming project.

The project was created to practice applying **C++ Object-Oriented Programming (OOP)** concepts to an interactive application, while learning how different game systems work together.

## ✨ Features

* **Sprite animation** — animated sprite loops for character movement and actions
* **Tiling map system** — builds the game environment from reusable tiles
* **Game state management** — separates different states and screens of the game
* **Object-Oriented Programming** — organizes game components using C++ classes and objects
* **Keyboard input** — handles player interaction through keyboard controls
* **2D graphics** — renders characters, environments, and other game assets using SFML

## 🛠️ Built With

* **C++**
* **SFML 2**
* **Object-Oriented Programming**
* **Visual Studio Code**

A compiled Windows executable is included in the repository.

Alternatively, the project can be compiled from `main.cpp` using a C++ compiler with **SFML 2** configured.
